DOCUMENTO DE IMPLEMENTACION
Estandarizacion de Modales (Header/Perfil + ControlBar) y Dropdown Base Reutilizable

Fecha: 2026-04-20
Proyecto: Web
Alcance de este documento: SOLO Header/Perfil y ControlBar

====================================================================
1) OBJETIVO
====================================================================

Unificar comportamiento, accesibilidad y API de los modales y dropdowns para:
- Reducir duplicacion de logica (Escape, foco, click afuera, cierre por eventos globales).
- Hacer que los modales de Header/Perfil y ControlBar sean practicamente hijos funcionales del Modal base.
- Tener un DropdownBase unico que se importe en los componentes que lo requieran.

Resultado esperado:
- Un contrato comun (API) para modales.
- Un contrato comun (API) para dropdowns.
- Migracion incremental sin romper estilos actuales.

3) COMPARACION TECNICA (MODAL BASE VS HEADER/PERFIL Y CONTROLBAR)
====================================================================

3.1 Modal base actual (Account/Modal.jsx)
- Ya tiene rol dialog y aria-modal.
- Ya maneja Escape para cerrar.
- Ya hace focus trap con Tab/Shift+Tab.
- Ya bloquea scroll del body al abrir.
- Ya permite footer simple o confirm/cancel via onConfirm.

Puntos a reforzar del base actual:
- aria-labelledby usa id fijo (modal-title), lo que puede duplicarse si hay mas de un modal abierto.
- No tiene opcion explicita para cerrar por click en overlay (actualmente no cierra).
- En modales anidados, conviene manejar stack para que solo el modal superior procese Escape y el scroll lock no se libere antes de tiempo.


3.2 Header/Perfil

A) DropdownAcount.jsx
- Es dropdown/menu, no modal.
- Tiene click afuera y semantica de menu.
- Lanza modales (Profile, Preferences, Logout) usando el Modal base.
Conclusion:
- Correcto usar Modal base para dialogs.
- El dropdown debe migrar a DropdownBase, no a Modal.

B) NotificationBell.jsx
- Es dropdown/menu de notificaciones.
- Tiene click afuera y apertura/cierre propios.
Conclusion:
- Debe usar DropdownBase para eliminar duplicacion y mantener menu accesible.

C) Header.jsx
- Compone NotificationBell, DropdownAcount y un modal de ayuda.
Conclusion:
- Debe consumir wrappers estandar (MenuDropdown, DialogModal) sin logica duplicada en el contenedor.


3.3 ControlBar

A) AddActivityButton.jsx
- Tiene modal propio (estructura de overlay/dialog personalizada).
- Tiene Escape, pero no toda la paridad de foco y manejo centralizado del base.
Conclusion:
- Debe migrar a Modal base (o wrapper hijo) conservando su contenido/estilos internos.

B) ThemeSelector.jsx
- Tiene panel tipo popup/modal, pero no contrato de dialog tan robusto como el base.
Conclusion:
- Si UX lo considera dialog, migrar a Modal base.
- Si UX lo considera panel flotante, migrar a DropdownBase con roleMode="panel".

C) FilterButton.jsx y AcademicPeriodSelect.jsx
- Son dropdowns con patron repetido (state + outside click + toggle + cierre por eventos externos).
Conclusion:
- Deben migrar a DropdownBase.


====================================================================
4) ESTRATEGIA: HACERLOS "HIJOS" DEL MODAL BASE
====================================================================

La idea no es forzar un solo JSX identico para todos, sino heredar comportamiento base.

Regla:
- "Hijo del Modal base" = componente que delega apertura/cierre, accesibilidad y teclado al base.
- Conserva layout y estilos del dominio (Add Activity, Preferences, etc.), pero sin reimplementar la mecanica modal.

Patron recomendado:
1) Mantener un ModalBase robusto (evolucionando src/components/Account/Modal.jsx).
2) Crear wrappers por dominio:
   - ProfileDialog
   - PreferencesDialog
   - AddActivityDialog
   - ThemeDialog (si aplica)
3) Cada wrapper solo define:
   - Titulo
   - Contenido
   - Botoneria/acciones
   - Clases de estilo propias
4) Todo lo demas (Escape, trap, ARIA, scroll lock, restore focus) queda centralizado.


====================================================================
5) API OBJETIVO PARA MODAL BASE (PROPUESTA)
====================================================================

Props minimas:
- isOpen: boolean
- onClose: function
- title: string
- children: node

Props opcionales recomendadas:
- onConfirm: function | null
- confirmLabel: string
- closeLabel: string
- closeOnOverlayClick: boolean (default false para compatibilidad actual)
- closeOnEsc: boolean (default true)
- showFooter: boolean (default true)
- initialFocusRef: ref opcional
- restoreFocusRef: ref opcional
- ariaLabel: string opcional (si no hay title visible)
- ariaDescribedBy: string opcional
- className, bodyClassName, footerClassName (extensibilidad visual)

Comportamiento obligatorio:
- Solo modal superior responde a Escape (si hay stacking).
- Scroll lock por contador de modales abiertos.
- id unico para titulo/descripcion ARIA.
- Focus trap robusto.

6) CODIGO PROPUESTO (TEXTO PLANO) - MODAL BASE CASI COPIABLE

Archivo sugerido:
src/components/common/ModalBase.jsx

import { useEffect, useId, useMemo, useRef } from "react";
import "./ModalBase.css";

const modalStack = [];
let lockCount = 0;

function lockBodyScroll() {
  lockCount += 1;
  if (lockCount === 1) {
    document.body.style.overflow = "hidden";
  }
}

function unlockBodyScroll() {
  lockCount = Math.max(0, lockCount - 1);
  if (lockCount === 0) {
    document.body.style.overflow = "";
  }
}

function getFocusableElements(container) {
  if (!container) return [];
  return Array.from(
    container.querySelectorAll(
      'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    )
  ).filter((el) => !el.hasAttribute("disabled") && !el.getAttribute("aria-hidden"));
}

export default function ModalBase({
  isOpen,
  onClose,
  title,
  children,
  onConfirm = null,
  confirmLabel = "Confirmar",
  closeLabel = "Cerrar",
  closeOnOverlayClick = false,
  closeOnEsc = true,
  showFooter = true,
  initialFocusRef,
  restoreFocusRef,
  ariaLabel,
  ariaDescribedBy,
  className = "",
  bodyClassName = "",
  footerClassName = "",
}) {
  const containerRef = useRef(null);
  const closeBtnRef = useRef(null);
  const instanceId = useId();

  const titleId = useMemo(() => `modal-title-${instanceId}`, [instanceId]);
  const descriptionId = useMemo(() => `modal-desc-${instanceId}`, [instanceId]);

  useEffect(() => {
    if (!isOpen) return;

    const previousFocus = document.activeElement;
    modalStack.push(instanceId);
    lockBodyScroll();

    const focusTarget = initialFocusRef?.current || closeBtnRef.current;
    focusTarget?.focus();

    const onKeyDown = (e) => {
      const isTopMost = modalStack[modalStack.length - 1] === instanceId;
      if (!isTopMost) return;

      if (e.key === "Escape" && closeOnEsc) {
        e.preventDefault();
        onClose();
        return;
      }

      if (e.key === "Tab") {
        const items = getFocusableElements(containerRef.current);
        if (items.length === 0) return;
        const first = items[0];
        const last = items[items.length - 1];

        if (e.shiftKey && document.activeElement === first) {
          e.preventDefault();
          last.focus();
        } else if (!e.shiftKey && document.activeElement === last) {
          e.preventDefault();
          first.focus();
        }
      }
    };

    document.addEventListener("keydown", onKeyDown);

    return () => {
      document.removeEventListener("keydown", onKeyDown);
      const i = modalStack.lastIndexOf(instanceId);
      if (i >= 0) modalStack.splice(i, 1);
      unlockBodyScroll();

      const restoreEl = restoreFocusRef?.current || previousFocus;
      if (restoreEl && typeof restoreEl.focus === "function") {
        restoreEl.focus();
      }
    };
  }, [
    isOpen,
    onClose,
    closeOnEsc,
    initialFocusRef,
    restoreFocusRef,
    instanceId,
  ]);

  if (!isOpen) return null;

  const handleOverlayClick = () => {
    if (closeOnOverlayClick) onClose();
  };

  return (
    <div className="modal-overlay" role="presentation" onClick={handleOverlayClick}>
      <div
        className={`modal-container ${className}`.trim()}
        ref={containerRef}
        role="dialog"
        aria-modal="true"
        aria-labelledby={title ? titleId : undefined}
        aria-label={title ? undefined : ariaLabel}
        aria-describedby={ariaDescribedBy || descriptionId}
        onClick={(e) => e.stopPropagation()}
      >
        <header className="modal-header">
          {title ? (
            <h2 id={titleId} className="modal-title">
              {title}
            </h2>
          ) : (
            <span className="sr-only">Dialog</span>
          )}

          <button
            ref={closeBtnRef}
            className="modal-close-btn"
            onClick={onClose}
            aria-label="Cerrar modal"
          >
            x
          </button>
        </header>

        <div id={descriptionId} className={`modal-body ${bodyClassName}`.trim()}>
          {children}
        </div>

        {showFooter && (
          <footer className={`modal-footer ${footerClassName}`.trim()}>
            {onConfirm ? (
              <>
                <button className="modal-secondary-btn" onClick={onClose}>
                  {closeLabel}
                </button>
                <button className="modal-action-btn" onClick={onConfirm}>
                  {confirmLabel}
                </button>
              </>
            ) : (
              <button className="modal-action-btn" onClick={onClose}>
                {closeLabel}
              </button>
            )}
          </footer>
        )}
      </div>
    </div>
  );
}


Explicacion clave del codigo ModalBase:
- modalStack + lockCount evita fallos tipicos en modales anidados.
- useId elimina colisiones de ids ARIA.
- closeOnOverlayClick configurable permite compatibilidad hacia atras.
- restoreFocus mejora UX y accesibilidad al cerrar.

src/components/DropdownBase/DropdownBase.jsx

import { useEffect, useId, useRef, useState } from "react";

function isControlled(open) {
  return typeof open === "boolean";
}

export default function DropdownBase({
  open,
  defaultOpen = false,
  onOpenChange,
  closeOnOutsideClick = true,
  closeOnEscape = true,
  closeOnSelect = false,
  roleMode = "menu",
  className = "",
  menuClassName = "",
  trigger,
  children,
}) {
  const [internalOpen, setInternalOpen] = useState(defaultOpen);
  const rootRef = useRef(null);
  const buttonRef = useRef(null);
  const menuRef = useRef(null);
  const id = useId();

  const currentOpen = isControlled(open) ? open : internalOpen;

  const setOpen = (next, reason) => {
    if (!isControlled(open)) setInternalOpen(next);
    onOpenChange?.(next, reason);
  };

  const toggle = () => setOpen(!currentOpen, "trigger");
  const close = (reason = "programmatic") => setOpen(false, reason);

  useEffect(() => {
    if (!currentOpen) return;

    const onDocMouseDown = (e) => {
      if (!closeOnOutsideClick) return;
      if (!rootRef.current?.contains(e.target)) {
        close("outside-click");
      }
    };

    const onDocKeyDown = (e) => {
      if (e.key === "Escape" && closeOnEscape) {
        e.preventDefault();
        close("escape");
        buttonRef.current?.focus();
      }
    };

    document.addEventListener("mousedown", onDocMouseDown);
    document.addEventListener("keydown", onDocKeyDown);
    return () => {
      document.removeEventListener("mousedown", onDocMouseDown);
      document.removeEventListener("keydown", onDocKeyDown);
    };
  }, [currentOpen, closeOnOutsideClick, closeOnEscape]);

  const roleByMode = roleMode === "listbox" ? "listbox" : roleMode === "menu" ? "menu" : undefined;

  return (
    <div ref={rootRef} className={className}>
      {trigger({
        ref: buttonRef,
        isOpen: currentOpen,
        onClick: toggle,
        "aria-haspopup": roleMode === "panel" ? "dialog" : "menu",
        "aria-expanded": currentOpen,
        "aria-controls": `dropdown-${id}`,
      })}

      {currentOpen && (
        <div
          id={`dropdown-${id}`}
          ref={menuRef}
          className={menuClassName}
          role={roleByMode}
        >
          {children({
            isOpen: currentOpen,
            close,
            select: () => {
              if (closeOnSelect) close("item-select");
            },
          })}
        </div>
      )}
    </div>
  );
}


Explicacion clave del codigo DropdownBase:
- Un solo punto para click afuera + Escape.
- Permite controlado/no controlado para no forzar refactors grandes de una sola vez.
- reason en onOpenChange facilita telemetria y debugging de cierres.
- roleMode evita usar la misma semantica para todos los casos.

- Luego migrar modales de formularios para minimizar regresiones funcionales.

14) CHECKLIST DE VALIDACION
====================================================================

Modales:
- Abre con foco inicial correcto.
- Tab/Shift+Tab no escapa del dialog.
- Escape cierra solo el modal superior.
- Scroll de body bloqueado mientras exista al menos un modal abierto.
- aria-labelledby/aria-describedby validos y sin ids duplicados.

Dropdowns:
- Trigger alterna apertura/cierre.
- Click afuera cierra.
- Escape cierra y retorna foco al trigger.
- aria-expanded y aria-controls correctos.
- Si closeOnSelect=true, una seleccion cierra el dropdown.

Integracion Header/Perfil + ControlBar:
- No hay listeners duplicados por componente para outside click/Escape.
- Se mantiene el estilo visual actual de cada modulo.
- Se conserva compatibilidad con onboarding/eventos globales existentes.
